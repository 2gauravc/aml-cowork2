# How to get started

Open the application at [http://100.51.23.165](http://100.51.23.165).

## Select a case

Choose one of the available cases to begin:

- **CROPWELL BISHOP CREAMERY LIMITED** — GB
- **SC ENGINEERING PRIVATE LIMITED** — SG
- **Ubizense Limited** — HK

You can find additional cases through the chatbot.

## Review the results

### CDD Maker

Use CDD Maker to review the due-diligence results. For detailed **Adverse News** and **Digital Footprint** findings, select the relevant button on the CDD Maker screen to open its dedicated results view.

To understand any result in more detail, ask the chatbot. The chatbot may occasionally give an incomplete or inaccurate answer; in that case, ask the bot to 'Refer to the case data in `CDDState`'.

### CDD Checker

Use CDD Checker for the detailed assessment. This view currently presents the raw assessment output.

### Tools

Run a tool independently, or load data from an existing CDD case.
